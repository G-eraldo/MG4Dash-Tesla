# Leçons

- Quand une personnalisation est demandée pour une application existante, intégrer d'abord la vue dans son module principal et ses flux de données avant d'envisager un module autonome.
- Après une correction de périmètre, repartir de la référence demandée et limiter les modifications aux surfaces nécessaires.
- Avant de proposer une application dans une carte intégrée, distinguer une application installée sur l’autoradio d’une application projetée depuis le téléphone.
