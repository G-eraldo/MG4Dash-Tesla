# Architecture du fork

Base : MG4Dash amont `5cf74ee7f59547a66a38ecc9aaf09021da302038`. Le module principal reste `app` et le module `rescue` amont est conservé ; aucun module de démonstration n’est ajouté. `MainActivity` instancie `ui/CustomHome.kt` quand `home_style=3`; les styles amont 0–2 et les autres pages restent disponibles. Les assets `app/src/main/assets/mg4custom/` dessinent la deuxième maquette Tesla en HTML/CSS/JS embarqué. Ils n’ouvrent aucun URL réseau ; le pont JavaScript expose uniquement des destinations et commandes média prédéfinies.

`CarBridge.state` fournit vitesse, batterie, autonomie et état One Pedal. Les mesures non alimentées (rapport, consommation, puissance) affichent « — ». `MediaHub.now` fournit titre et artiste et ses méthodes amont contrôlent la lecture. Les cartes climatisation, véhicule et énergie ouvrent les pages MG4Dash existantes ; navigation ouvre sa liste d’applications. Le raccourci « Réglages MG » ouvre la page Véhicule existante, qui propose déjà `Apps.VEHICLE` vers les réglages SAIC officiels. Aucun setter ADAS n’a été ajouté.

La préférence One Pedal est conservée dans `mg4_custom_preferences`, distincte de l’état du véhicule. Elle ne déclenche jamais `toggleOnePedal`. HomeSwitcher, Rescue, le garde crash, les services et le manifeste `src/car` sont préservés. Le manifeste ne déclare aucune activité additionnelle. Pour les mises à jour amont, comparer et fusionner les changements de `MainActivity`, Settings et assets ; la notification automatique de mise à jour est masquée pour éviter qu’une release officielle écrase le thème, la vérification manuelle restant accessible.
